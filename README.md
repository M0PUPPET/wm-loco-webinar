# WM-LOCO · D-Robotics Frontier #02

Slides for the D-Robotics Frontier #02 webinar: **How does a world model help humanoids cross stepping stones?**

**View online:** https://m0puppet.github.io/wm-loco-webinar/

Paper: [WM-LOCO: World-Model-Augmented Visual Locomotion for Humanoids on Foothold-Constrained Terrain](https://arxiv.org/abs/2609.02542) (arXiv 2609.02542)

## Viewing

Open the link above in a desktop browser (Chrome or Edge recommended), or clone the repository and open `index.html` locally; everything is self-contained.

| Key | Action |
| --- | --- |
| ← → / PageUp PageDown | previous / next slide |
| Space | play or pause the video on the slide |
| M | list of all slides |
| F | full screen |
| H | hide the toolbars |

The first slide is the demo video (2:12, with sound); click Play to start it. Figures with an *Enlarge* hint open full size on click.
`WM-LOCO_webinar_slides.pdf` is a static copy of the slides.
